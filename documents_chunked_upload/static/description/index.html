Documents Chunked Upload

Upload large files to Odoo Documents in small pieces, without timeouts or proxy size errors

AFTER INSTALLING YOU MUST SET THE PARAMETERS!

Without this step, files above Odoo's default upload limit (64 MB) are refused. Enter plain numbers only: no commas, spaces or units.

Option 1: in the Odoo interface

In developer mode go to TECHNICAL → PARAMETERS → SYSTEM PARAMETERS.

  • Search for web.max_file_upload_size and set it to 524288000 (recommended)
  • Search for document.max_fileupload_size and set it to 524288000 (recommended)

Option 2: in the Odoo Shell

Open the Odoo Shell (odoo-bin shell, or the Shell tab on Odoo.sh) and run these lines one at a time: 

env['ir.config_parameter'].sudo().set_param('web.max_file_upload_size', '524288000')
env['ir.config_parameter'].sudo().set_param('document.max_fileupload_size', '524288000')
env.cr.commit()
env.registry.clear_all_caches()
print(env['documents.document'].get_document_max_upload_limit())

The last line should print 524288000. 524288000 bytes is 500 MB; use a different number of bytes if you want a different limit. Then reload the page with Ctrl+Shift+R. If users still see the old limit, save the same two parameters once in the interface, or restart the server.

The problem

Companies that store technical drawings, scans or videos in Odoo Documents often hit a wall: a single upload of 100 MB or more is cut off by the web server or the hosting platform in front of Odoo, or it times out. Raising Odoo's own upload size limit does not help when the request never reaches Odoo.

Large PDFs have a second problem. Odoo's PDF text indexing reads every page in pure Python, which can keep the upload spinning for many minutes on a big drawing set.

What this module does

Chunked upload

Files above 60 MB are cut into 25 MB pieces in the browser and sent as separate small requests. The server stores the pieces temporarily, joins them, and saves the file through the standard Documents upload logic. Folder placement, links to projects, contacts or vehicles, permissions and the chatter note work exactly as for a normal upload.

Faster PDF uploads

PDFs above a size threshold (5 MB by default) are saved without full-text indexing, so a large drawing set is available in seconds instead of minutes. Smaller PDFs are indexed as before. The threshold is a system parameter.

Retries and progress

Each piece is retried up to three times. A notice shows the upload percentage, then "Processing..." while the file is assembled.

Built-in diagnostics

The final step writes timing lines to the server log. If it runs longer than 30 seconds, the log shows the current Python call stack every 30 seconds, so you can see exactly what is slow.

How it works

  1. You upload a file larger than 60 MB in Documents, as usual.
  2. The browser sends it in 25 MB pieces to a new route, /documents/upload_chunk.
  3. The server keeps each piece as a temporary record and removes leftovers automatically after 12 hours.
  4. The browser calls /documents/upload_finish. The server checks that all pieces are present and the size matches, joins them, and hands the file to the standard Documents upload.
  5. The pieces are deleted and the document appears in the folder or record you uploaded it to.

Files at or below 60 MB use the standard upload unchanged.

Configuration

The behavior is controlled by system parameters (Settings > Technical > System Parameters). Values must be plain numbers.

ParameterUnitPurpose
document.max_fileupload_size bytes Maximum file size accepted by Documents and by the chunk routes.
web.max_file_upload_size bytes Odoo's general upload limit, read by the web client.
documents_chunked_upload.pdf_index_max_mb MB PDFs above this size are not text-indexed. Default 5. Use 0 to skip all PDFs.

The chunking threshold (60 MB), piece size (25 MB) and retry count (3) are constants at the top of static/src/document_service_patch.js.

Requirements and limits

  • Odoo 19.0 with the Documents app (Odoo Enterprise) and the attachment_indexation module.
  • Tested on Odoo 19 Enterprise hosted on Odoo.sh, with files up to 190 MB. Larger files and many simultaneous uploads have not been tested.
  • Chunked upload is available to internal users.
  • The server holds the assembled file in memory while saving it, so very large files need enough worker memory.
  • PDFs above the indexing threshold cannot be found by searching for words inside them. They are still found by name, folder and linked record.
  • An interrupted upload cannot be resumed. The user starts it again, and abandoned pieces are cleaned up automatically.
  • The module extends Documents code, so re-test it after upgrading Odoo to a new version.

Installation

  1. Copy the documents_chunked_upload folder into your addons path (or your Odoo.sh repository) and restart or rebuild.
  2. Turn on developer mode, open Apps and click Update Apps List.
  3. Search for "Documents Chunked Upload" and click Install.
  4. Set the two upload parameters (see the red box at the top of this page). This step is required. Then reload the page.

Back up your database and test on a staging copy before installing on production.
